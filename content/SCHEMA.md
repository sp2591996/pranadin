# Content format `pranadin-content/1.0` (C1)

Owner: Content Creator · 17 Nov 2026. `app/CONTRACTS.md` does not exist yet, so this file defines the content contract. Engineering's zod schema (`app/src/content/schema.ts`, loaded by `load.ts`) enforces it. If the two ever disagree, the code wins and this file gets updated.

## Folder layout
| Path | Holds | Language |
|---|---|---|
| `data/*.json` | Language-neutral data: timings, dates, rotation, source keys | `none` |
| `en/*.json` | English text, final | `en` |
| `hi/*.json`, `mr/*.json` | Translations. Added **only after Board approval** | `hi`, `mr` |
| `<lang>/pages/*.md` | Trust pages (Markdown with front matter) | per folder |
| `lint/banned-claims.json` | Banned-claim regex rules used by the content build | n/a |

Drafts that have not been reviewed live outside the app in `15_Content/translations-draft/`. All files are generated by `node 15_Content/build/build-content.mjs`. Edit the masters in `15_Content/build/` rather than these files.

## Envelope (every JSON file)
```json
{ "$schema": "pranadin-content/1.0", "namespace": "ui", "lang": "en", "version": "2026-11-17.1", "status": "final" }
```
`status` is one of `draft` or `final`. `version` is the date plus a counter.

## Files
| File | Shape |
|---|---|
| `en/ui.json` | `strings`: a flat map `"key": "ICU message"`. The i18n key type is generated from this file, so a key the code uses but this file lacks breaks `tsc`. |
| `hi\|mr/ui.json` | `strings`: `"key": { "text", "reviewed": bool, "reviewer", "reviewedOn" }`. If `reviewed` is false or the key is missing, the app uses the English text for **that key only**. |
| `data/practices.json` | `techniques[]`: `id`, `level`, `retention` (always `false`), `pattern[]` of `{phase, labelKey, seconds}`, `defaultMinutes`, `cautionKey` (`safety.caution`), `safetyReviewed`. Also `meditations[]`. |
| `en/practices.json` | Text for each technique: name, subtitle, what, steps[5], skipIf[], source. For meditations: intro, cues[], closing, safety note. |
| `en/plan-cards.json` | `limits` (title 40, body 140) and `cards`: 12 cards (breath, stillness, reflection). |
| `data/plan-rotation.json` | `dayIndex` = local days since 2026-01-01 mod 7. Also `minutesByBudget` (5/10/20), 7-day rotation per goal (calm, sleep, focus, devotion, explore), `welcomeBack`, `ambienceByGoal` and the swap rule. |
| `en/journal.json` | `moods` (5) and `prompts` (prompt.01–30). Today's prompt = days since 2026-01-01 mod 30. |
| `data/observances.json` | `window`, `sourceKey` {KEY: {name, url}}, `flags`, `items[]`: `{id, date, endDate?, traditions[], status, flags[], sources[], check}`. |
| `en/observances.json` | Name and a neutral note (1–2 lines) per observance id. |
| `hi\|mr/{practices,plan-cards,observances,journal}.json` | Same shape as English, holding only Board-approved items. Each item has `reviewed: true`, `reviewer` and `reviewedOn`. The translated observance files repeat the English `note` with `noteLang: "en"`, because the schema requires a note and notes are not translated yet. |
| `en/pages/<slug>.md` | Front matter: `id: page.<slug>`, `title`, `lang`, `version`, `status`, `basis`. Slugs match `TRUST_PAGES` in `src/lib/routes.ts`: about, disclaimer, sources, ai-use, corrections (Content); privacy, terms, help (not written yet: Legal / Product). |

## Rules the build and loader check
1. **Placeholder parity:** every `{placeholder}` in English must appear in each translation, and no new ones may be added.
2. **Observances:** an item with status `verified` or `variable` is shown and needs **2 sources** from `sourceKey`. `hold` is hidden. Flags must be known (`region`, `moon`, `evening`). Dates must fall inside `window`.
3. **No breath-holds:** `retention` is false and no phase is a hold (PRD FR-4.1).
4. **Banned claims:** EN text in `en/` and `data/` must pass `lint/banned-claims.json`. Negations listed in `allowIfContext` are allowed.
5. **Unreviewed text never ships as reviewed:** only the Board sets `reviewed: true` (D-012).
6. **Approval freeze:** `15_Content/build/approvals.json` records Board decisions. Approved text is frozen in `15_Content/build/approved/`, and any later edit sends the item back to draft.
7. **Page placeholder:** the pages use `{{feedbackLink}}`, which the app replaces with the feedback or contact link (still to be supplied by the PMO).
